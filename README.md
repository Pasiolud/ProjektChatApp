This is project made in node.js with express using socket.io

This is older project for one of my subject's.

I saw that the database was not created automaticlly when you try to run main file (index.js) so I added that. The code of the project is kinda sloppy tbh. Request hell and it should be more organized. Not most of the logic in one file.

Open the console (terminal) in the folder where the project is located.
Type the command to start the server: node index.js Install the database if needed:
If the system reports an error about a missing SQLite database module, install it with the command: npm install sqlite3 Open the application:
Then go to your web browser and enter the local application address, which is usually: http://localhost:3000 You will be taken to the login page.
From there you can search for friends that also made an account and add them.
If they accept the friend request you can now both chat(The friend request's are not dynamic so you need to refresh page) - Now you can use chat.
